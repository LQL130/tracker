# Tracker Tổ Kiến — Ứng dụng iOS Offline + Tiện ích (Widget)

Dự án đã cập nhật phiên bản mới nhất của **Tracker cá nhân (Tracker tổ kiến)** với cơ chế **Thư đe dọa / Chiếm đóng khi trễ 3 việc** và thẻ thông báo ghim trên màn hình.

## Hướng dẫn tạo file cài đặt `.ipa` trên Windows
1. Giải nén file `.zip` này ra một thư mục trên máy tính Windows (giữ nguyên cả thư mục `.github`).
2. Tải toàn bộ file và thư mục lên **Repository** trên GitHub -> bấm **Commit changes**.
3. Vào tab **Actions** -> chọn workflow **Build iOS IPA** -> đợi khoảng **3–5 phút** để tải về gói **AntTracker-IPA** chứa file `AntTracker.ipa`.
4. Cắm cáp nối iPhone với Windows, mở **Sideloadly**, kéo thả file `AntTracker.ipa` vào và bấm **Start** để cài lên iPhone.
